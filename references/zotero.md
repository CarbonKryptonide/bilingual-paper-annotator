# Reading in Zotero

1. Render a standalone HTML reader from the verified paper data.
2. Drag the HTML file onto the original article's bibliographic item in Zotero or choose **Add Attachment → Attach Stored Copy of File**. This makes the reader a child attachment alongside the original, so bibliography metadata and the original PDF remain available.
3. In **Settings → General → Reader**, choose **Zotero** under **Open snapshots using**, then open the HTML attachment. Select text and try an underline or note. Close and reopen to confirm it still points to the selected sentence.
4. Test one chapter link and one figure reference and return link. The HTML has visible figures and no page scripts. If a Zotero build intercepts fragment navigation, the cited figure and locator still appear in reading order and can be found using text search.

Use a new attachment for revisions when an earlier snapshot already has user annotations. The existing annotations refer to its text, and changing or replacing that text can affect their location. Stored attachments may sync according to the user's Zotero settings. Check those settings before adding material that should stay local.

See [Zotero attachment handling](https://www.zotero.org/support/attaching_files) and [snapshot annotation support](https://www.zotero.org/support/7.0_changelog).
