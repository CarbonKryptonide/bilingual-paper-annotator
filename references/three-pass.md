# 三遍阅读自测

题目插在对应原文段落的右栏，AI 参考答案默认折叠。页首默认勾选已准备的遍次，可独立切换。取消勾选会同时隐藏该遍的题目和入口，全不选时可连续阅读正文。较旧的浏览器若不支持 CSS `:has()`，会直接显示读稿中的题目和入口。常规双栏精读可以省略 `study` 字段。

刚开始可只勾选第一遍。论文与自己的研究密切相关时，再做第二遍或第三遍。用户启用自测且未限定遍次时，准备全部 16 题，供读者切换。

## 第一遍：抓主旨，判断是否继续读

1. 作者想解决什么问题？
2. 作者用了什么方法？
3. 作者给出的主要答案是什么？
4. 为什么值得研究这个问题？
5. 前人做到哪里，还缺什么？
6. 我要不要继续读？为什么？

## 第二遍：看方法与证据

7. 研究对象、样本或材料从哪里来？
8. 研究中用了哪些重要指标？
9. 实验分哪几步？每一步得到什么结果？
10. 哪些关键图表支持主要结论？（记下结论、图表编号、关键结果或条件）
11. 研究成立依赖哪些假设或条件？
12. 这篇文章有哪些局限？（分开写“作者承认的”和“我的疑问”）
13. 作者提出了哪些后续研究方向？

## 第三遍：可选深入

14. 不看原文，我能怎样重建核心实验流程？
15. 哪些方法或想法可以用于我的研究？
16. 我还没懂什么？下一步查什么或读什么？

参考答案围绕该题给出一两段简要提示，并链接可回看的原文或图表。Q6、Q15、Q16 给判断依据或示例，把个人决定留给读者。Q12 分开写作者承认的局限与读者可追问的问题。Q13 只归纳作者明示的方向。Q14 保留复现实验所需的关键步骤，并标出尚缺的条件或数据。当来源没有给出答案时，提示读者在哪里核对。
